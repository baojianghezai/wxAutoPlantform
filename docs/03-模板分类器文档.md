# 模板分类器与渲染器文档

> 相关文件：
> - 分类/选择：`自动化脚本合集/templates/selector.py`
> - 配置：`自动化脚本合集/templates/selector_config.json`
> - 模板 HTML：`自动化脚本合集/templates/选出来/*.html`
> - 渲染：`自动化脚本合集/renderers/__init__.py`

## 1. 职责边界

- **selector.py**：根据结构化 JSON 里的 `content_type`（以及可选的 `template_id` / `style`）选出**模板文件**与**渲染器函数名**。
- **renderers/__init__.py**：把 JSON 的 `sections` 逐段渲染成公众号 HTML（**全内联样式**，单顶层 `<section>` 包裹）。

渲染策略说明：模板 HTML 是 96 编辑器成品文章、**无占位符**，所以不复用其结构，只从中提取**主题色**（ACENT 注释或出现最多的主色），`sections` 由渲染器独立生成。

## 2. 配置结构（selector_config.json）

```json
{
  "categories": {
    "recruitment": {"label": "招聘类"},
    "agriculture": {"label": "农业类"},
    "other": {"label": "其他"}
  },
  "source_categories": {
    "青岛市国企招聘": "recruitment",
    "山东华图": "recruitment"
  },
  "content_types": {
    "job_list": {
      "label": "招聘岗位",
      "category": "recruitment",
      "templates": [
        {"id": "zhaopin1", "name": "春季招聘（清新蓝）",
         "file": "选出来/招聘1.html", "style": "blue", "category": "recruitment",
         "description": "蓝天白云背景，清新正式，适合综合招聘"},
        {"id": "zhaopin2", "name": "企业招聘（纯白蓝）",
         "file": "选出来/招聘2.html", "style": "white_blue", "category": "recruitment",
         "description": "纯白背景+蓝色点缀，适合煤矿/能源等硬核行业"}
      ],
      "default": "zhaopin1",
      "renderer": "render_job_list"
    },
    "solar_term": {
      "label": "节气时令",
      "category": "agriculture",
      "templates": [
        {"id": "xiaoshu", "name": "大暑时节",
         "file": "选出来/节气-大暑.html", "style": "seasonal", "category": "agriculture",
         "description": "图文混排，适合节气、时令、节日内容"}
      ],
      "default": "xiaoshu",
      "renderer": "render_solar_term"
    }
  },
  "fallback": {
    "template": "选出来/招聘1.html",
    "renderer": "render_job_list"
  }
}
```

- `templates[].file`：相对 `templates/` 的模板 HTML 路径。
- `renderer`：内容类型对应的渲染函数名（反射调用，兜底 `render_generic`）。
- `categories`：全局分类定义（id→label），供前端分组 Tab 与 `/api/*` 输出。
- `source_categories`：**公众号名称→分类**映射表。爬虫/适配层（`crawler.py`、`adapter_task1.py`、`combine.py`）据此在代码层为每篇文章打 `source_category`，前端只按该字段渲染分组。
- `category`（content_types 块或单个模板）：模板归属分类，前端第二步按此分组；缺省时继承所属 content_types 块。

## 3. selector.py API

| 函数 | 说明 |
|------|------|
| `get_available_types()` | 所有已注册 content_type 列表 |
| `get_type_label(content_type)` | 内容类型的可读标签 |
| `list_templates(content_type)` | 该类型下全部候选模板 |
| `select_template(content_type, template_id)` | 选模板：① 显式 template_id（先当前类型、再全局查找）→ ② 类型 default → ③ fallback |
| `get_renderer_name(content_type)` | 该类型的渲染器函数名 |
| `classify_and_select(data)` | **主入口**：返回 `(template_info, renderer_name)` |
| `load_template_html(template_info)` | 读模板文件内容（按 `file` 相对 `templates/` 解析） |

`classify_and_select` 逻辑：
1. `content_type = data.get("content_type")`，`template_id` / `style` 可选。
2. `select_template(content_type, template_id)`；未注册时尝试 fallback。
3. **跨类型复用**：显式 `template_id` 不在当前类型时，会全局查找其他 content_types 的模板；命中后渲染器跟随该模板实际归属的类型（如 `job_list` + `template_id=xiaoshu` → 用大暑模板 + `render_solar_term`）。
4. 若数据显式带 `style`，覆盖到模板的 `style_override`（不影响文件选择）。

## 4. 渲染器（renderers/__init__.py）

### 入口

```python
render_article(data) -> str   # 完整公众号 HTML
```

流程：`importlib` 加载 `templates/selector.py` → `classify_and_select` → `load_template_html` → 反射调用渲染函数（不存在则 `render_generic`）。

### 三个渲染器

| 渲染器 | 触发 | 排版 |
|--------|------|------|
| `render_job_list` | `job_list` | 主题色 hero 色块 + 岗位卡片列表（无衬线） |
| `render_solar_term` | `solar_term` | 居中、文雅（楷体、留白多、分隔线） |
| `render_generic` | 其他/兜底 | 仅按顺序渲染 hero / paragraph / key_points |

### sections 支持的 type（`_SECTION_RENDERERS`）

| type | 渲染内容 |
|------|----------|
| `hero` | 标题横幅（job=色块 / solar=楷体居中+分隔线） |
| `cards` | 卡片列表：标题 + fields 键值对 + tags 标签 chip + description |
| `key_points` | 带圆点符的要点列表 |
| `paragraph` | 段落（可带 heading；solar 居中） |
| `image` | 图片 + 可选 caption |

### 主题色提取 `extract_accent(template_html)`

1. 模板中 `<!-- ACCENT:#xxxxxx -->` 注释优先（跳过近白/近黑/纯灰的无效色）。
2. 否则统计模板内出现次数最多的非灰阶 `#rrggbb`。
3. 兜底 `#237fb7`。

## 5. sections 契约（供大模型产出）

```json
{
  "content_type": "job_list | solar_term | 其他",
  "template_id": "可选：zhaopin1/zhaopin2/xiaoshu",
  "title": "公众号文章标题",
  "digest": "摘要（可选）",
  "sections": [
    {"type": "hero", "title": "...", "subtitle": "..."},
    {"type": "cards", "items": [
      {"title": "...", "fields": {"键": "值"}, "tags": ["..."], "description": "..."}
    ]},
    {"type": "key_points", "title": "...", "points": ["..."]},
    {"type": "paragraph", "heading": "可选", "text": "..."},
    {"type": "image", "url": "...", "caption": "可选"}
  ]
}
```

## 6. 新增一个模板/内容类型的步骤

1. 把模板成品 HTML 放到 `templates/选出来/`，在 `<!-- ACCENT:#... -->` 注释里标主题色（不标则自动统计主色）。
2. 在 `selector_config.json` 的对应 `content_types` 块加 `templates` 条目（id/name/file/style/description），或新建一个 content_type（需配 `renderer`）。
3. 若排版与现有渲染器不同，在 `renderers/__init__.py` 新增渲染函数（仿 `render_job_list`），并更新配置的 `renderer` 字段。
4. 可选：更新 `docs/01-n8n设计.md` 的大模型 prompt 里支持的 content_type 说明。
